# Raw Source 02: 費南雪 (Financier) 與焦化奶油 (Beurre Noisette) 的梅納反應科學

- **來源類型**：食品化學文獻與法式甜點實作筆記
- **收錄日期**：2026-11-22
- **涵蓋主題**：費南雪 (Financier)、焦化奶油 (Beurre Noisette)、梅納反應 (Maillard Reaction)、杏仁粉 (Almond Powder)、轉化糖漿 (Trimoline)

## 1. 為什麼費南雪跟瑪德蓮長得像，靈魂卻完全不同？

初學者最常把瑪德蓮（貝殼蛋糕）與費南雪（金磚蛋糕）搞混。從配方結構來看，兩者有三大本質差異：
1. **蛋的部位**：瑪德蓮使用**全蛋（含蛋黃卵磷脂乳化）**；費南雪只使用**純蛋白（Egg Whites）**，組織更緊實有彈性。
2. **粉類結構**：瑪德蓮是 **100% 低筋麵粉**；費南雪則是 **杏仁粉 (Almond Powder) 大於或等於低筋麵粉**（常見杏仁粉 : 低筋麵粉 = 1:1 甚至 6:4），提供極高的油脂香氣與濕潤度。
3. **奶油狀態**：瑪德蓮多用一般融化奶油；費南雪的核心靈魂則是煮到深琥珀色、散發濃烈榛果香氣的**焦化奶油 (Beurre Noisette / Brown Butter)**。

## 2. 兩大流派配方紀錄

### 流派 A：巴黎百年老店經典金磚派 (Classic Parisian — 外脆內Q、重杏仁焦香)
- 低筋麵粉 (T45/T55)：60g
- 美國杏仁粉 (Almond Powder)：60g *(註：總粉量 = 低粉 60g + 杏仁粉 60g = 120g)*
- 純糖粉 (Icing Sugar)：150g
- 蛋白 (Egg Whites)：150g
- 發酵無鹽奶油 (煮成焦化奶油前原重)：180g *(註：焦化後蒸發水分約剩 145~150g)*
- **烤溫與工序**：210°C 高溫快烤 11~13 分鐘，追求四邊極致酥脆、邊角焦糖化。

### 流派 B：現代精品甜點主廚流派 (Modern Patisserie — 添加轉化糖漿，極致保濕耐放)
- 低筋麵粉：50g
- 西班牙帶皮杏仁粉：70g *(註：總粉量 = 50g + 70g = 120g)*
- 細砂糖：110g
- 轉化糖漿 (Trimoline / 蜂蜜亦可)：20g
- 蛋白：130g
- 焦化奶油 (濾除過焦沉澱後淨重)：140g
- 泡打粉：2g
- **烤溫與工序**：200°C 烘烤 13~15 分鐘，出爐後趁熱刷上一層薄焦化奶油封住水氣。

## 3. 焦化奶油 (Beurre Noisette) 的三階段梅納反應 (Maillard Reaction)

天然奶油並非 100% 油脂，其組成為：**約 82~84% 乳脂肪 + 14~16% 水分 + 1~2% 乳固形物（酪蛋白、乳糖）**。加熱煮製焦化奶油時會經歷三個物理化學階段：

1. **第一階段（60°C ~ 100°C）：融化與油水分離**
   - 乳化結構破壞，水分沉底並開始沸騰蒸發，表面冒出大量大氣泡，發出劈啪聲（大聲咆哮期）。此時溫度被沸水鎖在 100°C 左右，**絕對不會發生梅納反應**。
2. **第二階段（115°C ~ 140°C）：水分蒸發完畢與梅納反應啟動**
   - 劈啪聲突然變小並轉為安靜的細密泡沫（沉默期）。因為水分蒸發殆盡，油溫迅速突破 120°C！
   - 奶油中那 **1~2% 的乳蛋白質（胺基酸）與乳糖（還原糖）** 在高溫下發生劇烈的**梅納反應 (Maillard Reaction)**，產生吡嗪（Pyrazines）等數百種揮發性芳香化合物，散發出迷人的烤榛果香氣（法文 *Noisette* 即為榛果之意），底部乳固形物轉為金黃琥珀色。
3. **第三階段（> 155°C ~ 165°C）：碳化焦黑（危險區！）**
   - 乳固形物迅速由深琥珀色轉為黑色碳化，產生苦味與致癌丙烯醯胺。因此一聞到濃郁榛果香、看到琥珀色沉澱（約 145~150°C），必須**立刻將鍋底泡冰水降溫（Stop the cooking）**！

## 4. 常見失敗與排錯
- **費南雪吃起來毫無榛果香、像普通雞蛋糕**：
  - 原因：煮奶油時看到冒泡泡就關火（還在 100°C 排水期，根本沒進入 130°C 梅納反應區），或者濾掉了所有琥珀色乳固形物焦香精華。
- **費南雪表面滲油、底部油膩濕軟**：
  - 原因：焦化奶油沖入麵糊時溫度過高（>75°C 把蛋白燙熟結塊），或攪拌不足導致油脂沒有被蛋白與粉類包覆乳化。
